 Sample Superstore Data Analysis:

 Project Description:
This project analyzes the Sample Superstore dataset using Python in Google Colab. It uses basic data analysis and visualization to understand sales and profit.

 Libraries Used:
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy

 Dataset:
File Name:
samplesuperstore - samplesuperstore.csv

 Steps Performed:
1. Imported required libraries.
2. Loaded the dataset.
3. Displayed the first 5 rows.
4. Checked dataset information.
5. Found missing values.
6. Calculated average sales using NumPy.
7. Grouped sales by category using Pandas.
8. Created a bar chart using Matplotlib.
9. Created a scatter plot using Seaborn.
10. Split the dataset using Scikit-learn.
11. Calculated mean sales using SciPy.

 Output:
- Dataset preview
- Dataset information
- Missing values
- Average sales
- Sales by category
- Bar chart
- Scatter plot
- Training and testing data count
- Mean sales
